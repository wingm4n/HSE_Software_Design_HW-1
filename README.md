Решения:  
разделяю бизнес-логику с абстракциями предметной области (Application + Domain) и консольный интерфейс (Console) - позволяет в будущем изменить UI на любой другой, не меняя бизнес-логику

Использование ИИ (no code): обсуждение структуризации решения (разбиение на папки и файлы проекта) - DeepSeek V4.
Использование ИИ (code) : написание однотипных классов по заданному образцу - DeepSeek V4.

SOLID + DI: DI явный, SOLID - L не отслеживается, но поддерживается в Things, может нарушаться в Transport - самый слабый. S + I среди Thnigs и Тransport (и всеми интерфейсами) = O (сильный). D - сквозной, везде в program будут исп. интерфейсы и абстрактные классы, а не сами предметы.
